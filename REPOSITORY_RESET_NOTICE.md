# Clean repository history

This project is prepared as a fresh root commit from the approved local Rust source. It must not be merged with the previous GitHub history.

Clones based on the previous history should be replaced with fresh clones. Forks, pull request references, cached GitHub views and prior copies can retain historical content until separately addressed.

Do not commit Telegram credentials, user conversations, chat identifiers, production databases, logs, backups or runtime files. The production service on dns is independent from GitHub updates.

Automatic release and scheduled actions are intentionally excluded from this clean-root candidate. Security advisories and quality warnings must be reviewed before a release is approved.

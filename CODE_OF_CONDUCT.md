# Code of Conduct

## Our standards

Contributors and maintainers are expected to communicate respectfully, focus criticism on ideas and code, welcome constructive technical disagreement, and avoid harassment, discrimination, threats, or disclosure of private information.

## Scope

This code of conduct applies to repository discussions, issues, pull requests, reviews, and other project spaces where a participant is representing the project.

## Enforcement

Report conduct concerns privately to the repository owner through an existing trusted contact channel. Maintainers may edit or remove inappropriate content, close or lock discussions, or restrict participation when necessary to protect the project community.

Enforcement decisions should be proportionate, documented when appropriate, and made consistently regardless of a contributor's role or status.
